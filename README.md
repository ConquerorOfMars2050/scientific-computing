# Scientific Computing & Computational Physics

This repository documents my work through Dr. Börge Göbel's 
**Computational Physics: Scientific Programming with Python** course (Udemy, 21 hours).

## Status: Course Complete ✅ — Completed August 2026

## Topics Covered

**Python & Numerical Foundations**
- NumPy fundamentals, vectorization, array manipulation
- Fitting a polynomial model function
- Generalized polynomial interpolation
- Fourier transform

**Differential Equations & Dynamical Systems**
- Multidimensional 3-body problem (orbital mechanics)
- Multidimensional heat equation
- Multidimensional Lorenz system (chaos)
- Eigenvalue analysis of coupled oscillators

**Physics Simulations**
- Monte Carlo estimation of Pi
- Monte Carlo magnet simulation (Ising-type model)
- Particle in a box
- Quantum harmonic oscillator
- Electronic band structure of graphene
- Magnetic field of a current-carrying wire
- Rotation of geometric objects
- Rolling ball dynamics
